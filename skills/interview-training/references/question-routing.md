# Question Routing

- `PROJECT`: architecture, decisions, failures, trade-offs, ownership → Project Deep Dive.
- `BEHAVIORAL`: conflict, leadership, difficult delivery, learning → Story Bank.
- `KNOWLEDGE`: concepts/frameworks/algorithms → JD-driven learning assets.
- `SYSTEM_DESIGN`: combine verified experience with explicit hypothetical design; keep the boundary clear.
- `JD_SPECIFIC`: start from the current JD requirement and route to the strongest verified evidence.
