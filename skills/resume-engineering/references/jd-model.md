# JD requirement model

Use this before selecting resume content.

## Single-JD extraction

Capture these fields:

- role/company/source/stable job identity;
- hard constraints: location, education, years, language, schedule, required credentials;
- core responsibilities;
- must-have technical capabilities;
- preferred/bonus capabilities;
- domain/product context;
- seniority and ownership expectations;
- repeated terminology and exact phrases that are safe to mirror when factual;
- explicit deliverables or outcomes;
- ambiguous/unrealistic requirements and red flags;
- missing information that should remain unknown.

Separate what the JD literally states from what is inferred.

## Requirement priority

Use `MUST`, `CORE`, `PREFERRED`, `CONTEXT` rather than an opaque percentage.

- `MUST`: explicit screen/deal-breaker or clearly indispensable to the described work.
- `CORE`: central to daily success even if not written as a formal hard gate.
- `PREFERRED`: bonus or differentiator.
- `CONTEXT`: environment/domain signal that helps choose examples but should not dominate.

A repeated phrase is evidence of emphasis, not automatic proof that it is a hard requirement.

## Role success story

Summarize in 2–4 sentences:

1. what problem this hire is expected to solve;
2. what kind of engineering judgment/ownership matters;
3. which 3–6 capabilities are likely to separate strong candidates;
4. what would make an otherwise strong resume look mismatched.

## Corpus and clustering

For multiple JDs, normalize each JD first, then cluster by requirement pattern—not title alone.

Useful cluster features:

- frontend/full-stack balance;
- AI/Agent application depth;
- platform/devtools/R&D-efficiency expectations;
- backend/runtime/data expectations;
- browser/desktop/tooling expectations;
- system-design/ownership seniority;
- domain constraints and education risk.

Do not force a preselected number of clusters. If a cluster is supported by only a few incomplete JDs, mark it tentative and collect more data before generating a baseline resume.
