# Template Research Contract

## 目的

在候选人正式内容填充前，独立完成**中文资深工程师 Markdown 内容模板**研究与筛选。

当前 Template Research Mode 研究的是“内容怎么组织”，不是“怎么渲染”。

## 允许输入

- 真实公开 Senior / Staff / Principal / Architect 简历的文本内容；
- r/EngineeringResumes、ExperiencedDevs、The Tech Resume Inside Out、Pragmatic Engineer 等写作方法；
- Resume/CV Agent Skill 中的事实、选材、写作、Reviewer 机制；
- 仅用于内容压力测试的目标画像：中文、约 10 年经验、资深 IC、复杂技术项目较多。

禁止把 Career Facts / Material Units 填入模板正文。

## 明确排除

当前 Gate 不研究、不评分、不验收：
- RenderCV / LaTeX / XeLaTeX / YAML renderer；
- PDF / PNG / 图片预览；
- CJK 字体、字号、分页；
- ATS 抽取、ATS 模板评分；
- 一页 / 两页的视觉适配；
- GitHub Star 高低对应的版式排名。

这些历史资产可以保留，但不得进入当前决策链。

## 输出

Template Research Mode 只允许产出：
- 中文内容模板标准；
- 真实高级工程师内容组织规律；
- Skill / 社区写作机制；
- 3～4 份使用中性虚构内容的**完整中文 Markdown 标杆简历**；
- 对每份 Markdown 从第一行到最后一行的自审记录。

## 退出条件

必须同时满足：
1. 3～4 份完整 Markdown 标杆已生成并通读；
2. 旗舰项目、普通项目、早期经历和最近 4～5 年的深浅关系可见；
3. 用户亲自读过并选择/批准 1～2 种内容结构；
4. 用户明确同意进入真实内容填充。

在此之前：`NO_CANDIDATE_FILLING = TRUE`。
