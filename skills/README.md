# Skills

Skills describe how an AI agent should use the deterministic product/runtime.

- `job-search` — discover, normalize, evaluate and shortlist jobs without auto-applying.
- `resume-engineering` — select evidence and tailor resumes without inventing facts.
- `interview-training` — run structured interview practice, feedback and growth loops.

Skills are workflow contracts, not privileged runtimes. External side effects remain explicit and user-authorized.
