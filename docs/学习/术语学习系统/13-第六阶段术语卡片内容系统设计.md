## 1. 目标

T6 把 T1/T2 的“术语节点 + 关系”升级成真正可学习内容。

首批固定覆盖：Interview 41 个技术 Topic 引用的 **103 个唯一 Canonical Term**。

## 2. Authority

- `data/terms-v1.json`：Canonical Term Truth；
- `data/term-graph-v1.json`：关系 Truth；
- `data/term-cards-v1.json`：教学内容 Truth；
- `data/term-card-sources-v1.json`：教学来源 Truth；
- SQLite：仍只保存个人 progress / review / calibration。

Card 不能反向修改 term id、canonical name、graph edge 或 Career Facts。## 3. Compact Curated Card Schema

每张首批卡必须有：
- `plainDefinition`：白话定义；
- `background`：为什么出现 / 解决前代什么问题；
- `purpose`：解决什么；
- `mechanism`：核心机制；
- `boundaries`：易混概念与责任边界；
- `failureTradeoffs`：失败与取舍；
- `interview30s`：30 秒面试表达；
- `sourceRefs`：受控来源；
- `contentStatus / reviewedAt`。

前置、上下游、chains、priority、progress 不重复保存，由 T1/T2/T3 Runtime 动态组合。

## 4. Runtime

`learning.term_lookup` 在原返回值基础上增加 `card`；未物化词返回 `card:null`，禁止自动编造。

新增 `learning.get_term_card_coverage`：只读返回首批 103 的 materialized / missing / source coverage。

## 5. Gate

首批 PASS 必须满足：103/103 materialized；每卡全部必填字段非空；termId 全部存在于 Canonical Corpus；sourceRef 全部存在于 Source Registry；`term_lookup` 对 MCP/RAG/HTTP/Transaction/React Render 可返回 Card；旧 progress/graph/Interview Bridge 不回归。
