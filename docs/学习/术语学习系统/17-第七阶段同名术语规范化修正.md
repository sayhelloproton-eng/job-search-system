# T7｜Canonical 同名词修正

> 日期：2026-09-08
> 状态：**PASS / HOMONYM_SPLIT / KEY**

## 1. 发现

T7 Wave2 构建 Card 时发现 `Key` 同时来自：

- Agent A0：Attention 的 Query / Key / Value；
- Frontend F10：React 列表 reconciliation 使用的 `key`。

两者同名但语义完全不同，原 T1 以字符串合并为一个 Canonical Node，属于高召回 Canonicalization 的漏网 homonym。

## 2. 修正

- 原 `Key` 拆为 `Attention Key` 与 `React Key`；
- 原 Graph `Key → Attention` 关系迁移到 `Attention Key`；
- `React Key` 暂作为非 Hub canonical term，后续按 Frontend 内容 Wave 单独物化；
- 泛化输入 `Key` 不设置 alias，避免 Runtime 猜测用户指哪一个语义。

结果：Canonical Terms `1406 → 1407`；Graph 仍为 `411 Hub / 436 Edge`。
