# T3｜Terminology Learning Runtime SDD

> 日期：2026-09-08
> 状态：**T3_SDD_FROZEN / TDD_NEXT**

## 1. 目标与边界

T3 把 T1 Canonical Corpus + T2 Term Graph 变成可调用学习能力，不重新定义术语内容。

固定 Authority：
- `data/terms-v1.json`：术语 canonical truth；
- `data/term-graph-v1.json`：术语关系 truth；
- SQLite：只保存用户 Learning State / Review State / Progress History；
- Interview / JD：只产生学习输入和优先级信号，不改 canonical definition。

禁止：学习进度自动升级 Career Fact、Resume Evidence 或生产经验。
## 2. Runtime 操作

1. `learning.term_lookup`：canonical / alias 精确解析，返回 term、neighbors、progress；
2. `learning.search_terms`：按 canonical / alias 子串检索，默认最多 20；
3. `learning.plan_term_path`：`CHAIN / BETWEEN / PREREQUISITE` 三种路径；
4. `learning.record_term_progress`：追加 Progress Event，并更新当前快照；
5. `learning.get_term_progress`：读取当前状态与最近历史；
6. `learning.list_due_reviews`：读取到期复习项。

所有操作：`careerFactsMutable:false`。只有 `record_term_progress` 有持久化副作用。
## 3. Learning State Authority

固定状态：`UNSEEN → RECOGNIZE → EXPLAIN → CONNECT → APPLY → DEBUG → DESIGN → INTERVIEW_READY`。

规则：
- 状态只能由 `learning.record_term_progress` 显式推进或回退；
- 每次写入必须追加 immutable progress event；
- current snapshot 只是 event history 的物化视图；
- `confidence` 与 `state` 分开保存，不能用模型置信度替代用户掌握状态；
- `next_review_at` 可以为空；进入 `EXPLAIN+` 后默认允许进入复习调度；
- 学习状态不修改 `terms-v1.json` 中的静态 `learningState` 占位字段。

## 4. Path Planning

`PREREQUISITE`：从目标 term 反向沿 `PREREQUISITE_OF` 找必要前置，返回最短可解释路径；
`BETWEEN`：两个 term 间按无向可学习关系求最短路径；
`CHAIN`：按指定 `agent/frontend/backend/fullstack/shared` 过滤后，从 root 到 target 求路径。

路径规划默认忽略 `FAILURE_RELATED`，除非显式要求；`CONTRASTS_WITH` 作为解释边，不作为默认 prerequisite。
## 5. SQLite 最小模型

Migration 007 只新增两表：
- `learning_term_progress`：每个 term 一行当前快照；
- `learning_term_progress_events`：append-only 历史。

快照字段至少包含：`term_id / state / confidence / source_type / source_ref / next_review_at / updated_at`。
事件字段至少包含：`id / request_id / term_id / from_state / to_state / confidence / note / source_type / source_ref / created_at`。

`request_id` 唯一，保证写入幂等；event 禁止 UPDATE/DELETE。静态 term/edge 不入 SQLite。

## 6. Failure / Security Boundary

未知 term → `LEARNING_TERM_NOT_FOUND`；未知 alias 不做模糊自动纠正。
非法 state → `LEARNING_STATE_INVALID`；未知 path mode → `LEARNING_PATH_MODE_INVALID`。
写入必须先验证 term 存在于 canonical corpus，再开始事务。

## 7. T3 Gate

必须通过：lookup alias、search、prerequisite path、between path、progress append/history、request-id idempotency、due review、Career Fact 0 mutation、旧 Learning Bridge 回归、`git diff --check`。

`T3_RUNTIME_PASS` 之前不得进入 T4 自动反馈接线。
