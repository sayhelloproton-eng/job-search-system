## 1. Agent / MCP

- OpenAI Agents SDK（Python / TypeScript）：Agent、Agent Loop、Tool、Handoff、Guardrail、Session、HITL、Tracing。
- MCP 官方 Architecture / Specification：Host、Client、Server、Data Layer、Transport Layer、Tools、Resources、Prompts、Capability Discovery、Authorization。
- 内部 `ai-modern-evolution`：作为已审阅的**概念发现与关系语料**，覆盖 `模型智能 → 知识/能力 → Agent/Workflow → Harness/Runtime → Multi-Agent → Execution/Eval → AI Platform/Product`；它不能覆盖官方协议定义，但必须参与术语召回、前置关系和“为什么出现”的演进背景。

当前特别注意：MCP 官方 2026-07-28 文档已经把协议描述推进到新的 discovery/statelessness 模型，并明确 Sampling / Logging 为 deprecated；因此 MCP 类 Term Card 必须带协议版本和 freshness，不能把 2025 教程永久当真源。

## 2. Frontend / Web

- MDN Web Docs：Client/Server、HTTP、Browser、DOM、Web Rendering、Web API、安全与网络基础。
- React 官方：Render / Commit、State、Hooks、Suspense、Server Components、Server Functions、Actions / Transitions 等 React 运行时概念。
- Next.js 官方：Server/Client Components、Route Handlers、Streaming、Hydration、App Router、Cache Components / Partial Prerendering、`use cache` 等 Full-stack React 框架概念。

原则：Web 基础以 MDN / Web 标准为主，React/Next 只能解释框架如何实现，不反向改写浏览器基础定义。
## 3. Backend / Data

- Node.js 官方：Event Loop、Worker Pool、Stream、Backpressure、`worker_threads`、AsyncLocalStorage / async hooks、进程与诊断行为。
- PostgreSQL 官方：Transaction、Isolation、MVCC、Lock、Index、Query Planner、WAL、Partitioning、Replication、VACUUM 与并发控制。
- FastAPI 官方：typed API、async、Dependency Injection、security integration 等 Python 服务端概念。

## 4. Delivery / Infra

- Docker 官方：Image、Container、Layer、Registry、Volume、Network、Compose 与容器运行边界。
- Kubernetes 官方：Deployment、StatefulSet、Service、Pod、Probe、HPA/VPA、PDB、Gateway/Ingress、调度与滚动发布等运行概念。
- OpenTelemetry：Trace / Span / Metric / Log、Context Propagation、Baggage、Instrumentation、Sampling、Semantic Conventions 等跨语言可观测标准。
- OWASP：后续补 Auth / XSS / CSRF / API Security 的安全真源。

## 5. Source Grade

- `S0_STANDARD`：协议/标准/规范；
- `S1_OFFICIAL`：语言、数据库、框架官方文档；
- `S2_MAINTAINER`：项目维护者或官方工程博客；
- `S3_ENGINEERING`：高质量工程资料；
- `S4_COMMUNITY`：社区解释、面经、博客，只用于发现术语和现实问法。

定义和机制优先 S0/S1；S4 不能独立改写 canonical definition。

## 6. Freshness

- Stable concept：默认 12 个月审查一次；
- Evolving standard：进入学习/面试前检查最新版本；
- Framework-specific：默认 90～180 天检查；
- Market term：每次新 JD / 新面试出现时重新判断语义。

术语卡必须保存 `sourceRef + retrievedAt + versionIfKnown`，避免“学会的是旧框架行为”。
