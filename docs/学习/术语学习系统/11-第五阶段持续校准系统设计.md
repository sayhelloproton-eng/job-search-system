# T5｜Terminology Continuous Calibration SDD

> 日期：2026-09-08
> 状态：**T5_SDD_FROZEN / TDD_NEXT**

## 1. 目标

T5 负责“发现变化、保存证据、形成待裁决队列”，不负责自动改 Canonical Corpus。

固定链路：
`JD / Interview / Official Doc → Candidate or Freshness Signal → Calibration Evidence → Curated Batch → T1/T2 Truth Update`。

禁止：
- 单条 JD / 单次面试直接新增 canonical term；
- Runtime 自动修改 `terms-v1.json / aliases-v1.json / term-graph-v1.json`；
- Calibration 结果自动修改 Career Facts / Resume Evidence / Learning State。

## 2. Runtime Surface

1. `learning.record_term_candidate`：记录显式新术语候选及来源；
2. `learning.list_term_candidates`：读取候选队列；
3. `learning.audit_term_freshness`：按 term class + 最近校准时间形成 freshness 队列；
4. `learning.record_term_calibration`：记录官方核验结论，不自动改静态 truth。
## 3. Freshness Policy

默认审查窗口：
- `STABLE_CONCEPT`：365 天；
- `EVOLVING_STANDARD`：30 天；
- `FRAMEWORK_SPECIFIC`：120 天；
- `MARKET_TERM`：30 天，且新 JD / 面试出现时重新判断。

Freshness baseline 优先使用该 Term 最近一次 calibration event；没有 event 时使用 corpus `generatedAt`。

## 4. Persistence

Migration 008 只保存校准过程：
- `learning_term_candidates`：候选当前聚合状态；
- `learning_term_candidate_events`：append-only 来源历史；
- `learning_term_calibration_events`：append-only 官方/维护者核验历史。

Calibration outcome：`CONFIRMED / UPDATE_REQUIRED / DEPRECATED / ALIAS_CHANGE / RELATION_CHANGE`。

候选即使达到多次出现，也只能进入 `READY_FOR_CURATED_REVIEW`，不能自动升格 canonical。

## 5. Gate

必须验证：request-id 幂等、Candidate provenance、Freshness 排序、Calibration append-only、静态 JSON 零 mutation、Career Facts / Learning State 零自动 mutation。
