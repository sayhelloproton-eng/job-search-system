# Course Learning System｜课程学习系统设计

> 日期：2026-09-09
> 状态：**C1_CONTENT_LAYER_PASS / C2_RUNTIME_PASS / 7_OF_7_COURSE_UNITS**

## 1. 目标

把 `docs/学习/内容/01～07` 的旧 Markdown 课程升级成正式 Learning Runtime 内容，而不是复制或重写第二套知识库。

固定分工：

```text
Term Card = 一个概念是什么、为什么、怎么工作、边界与取舍
Course Unit = 一组概念如何组合成可解释、可实践、可排错、可设计的能力
Interview Corpus = 面试如何验证这些能力
Career Facts = 真实做过什么；学习永远不能自动改写
```

## 2. Authority

- 原课程 Markdown：历史课程 Source；原文保留，不覆盖。
- `data/course-units-v1.json`：结构化 Course Unit Content Truth。
- `terms-v1.json / term-graph-v1.json`：Course Unit 引用的概念 Truth。
- SQLite：只保存个人 Course Progress / Review Event；不保存课程正文副本。
- Interview Learning Bridge：只产生学习输入和复练回流，不修改 Course/Term Truth。

## 3. Course Unit V1 Schema

每个 Course Unit 至少包含：
- `id / title / chains / priority / sourceDoc`；
- `prerequisiteUnitIds`：课程级前置；
- `why`：为什么目标岗位需要；
- `mentalModel`：最小系统图/心智模型；
- `contentSections`：机制、边界、选型等课程主体；
- `linkedTerms`：必须指向 Canonical Term ID；
- `unresolvedConcepts`：课程出现但词库尚未 Canonical 的候选词；
- `failurePractice`：故障、恢复、系统设计或代码验收；
- `interviewTransfer`：课程知识如何转成面试表达；
- `evidenceBoundary`：学习与真实经历的边界；
- `officialVerification`：原课程已有的真源核验；
- `contentStatus / reviewedAt`。

## 4. 第一批固定 7 Unit

1. `course.agent-runtime`：Agent Runtime / Tool / MCP / Permission；
2. `course.rag-retrieval`：RAG / Retrieval / Vector DB；
3. `course.python-fastapi`：Python / FastAPI 第二服务端路径；
4. `course.backend-production`：Backend Production Completeness / System Design；
5. `course.context-state-memory`：Context / State / Memory / Orchestration；
6. `course.testing-eval-reliability`：Testing / Eval / CI / Docker / Reliability；
7. `course.framework-fde-system-design`：Framework / FDE / System Design。

旧 `面试题库.md / 高匹配岗位专项面试包.md` 不迁成 Course Unit，继续由 Interview System 消费；`30秒与3分钟回答库.md` 后续作为 Speaking/Transfer 层处理，不与课程正文混在一起。

## 5. Term Bridge

Course Unit 不自己定义术语。每个核心概念必须：

`Course Unit → canonicalName → termId → Term Card / Graph / Progress`

找不到 Canonical 的课程概念必须 fail-closed 到 `TERM_CANDIDATE_REVIEW_REQUIRED`，不得临时造 termId。

首轮迁移已发现 9 个候选：`ACL / FastAPI / Pydantic / Dependency Injection / HTTPX / Lifespan / pytest / Groundedness / FDE`。

## 6. Learning State

课程沿用术语系统相同掌握梯度：

`UNSEEN → RECOGNIZE → EXPLAIN → CONNECT → APPLY → DEBUG → DESIGN → INTERVIEW_READY`

但 Term Progress 与 Course Progress 分开存储：认识 MCP 不等于完成 Agent Runtime 课程；完成课程也不自动把每个 Term 升级。

## 7. C2 Runtime Contract

下一阶段固定操作：
- `learning.list_course_units`
- `learning.course_lookup`
- `learning.plan_course_path`
- `learning.record_course_progress`
- `learning.get_course_progress`
- `learning.list_due_course_reviews`
- `learning.get_course_coverage`

所有操作 `careerFactsMutable:false`；只有 `record_course_progress` 有持久化副作用。

## 8. Gate

C2 Runtime PASS 条件：lookup / path / progress append-only / request-id 幂等 / due review / Course↔Term link / Interview Bridge 回归 / Career Fact 0 mutation / `git diff --check` 全部通过。
