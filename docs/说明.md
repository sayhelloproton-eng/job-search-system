# Docs

这里放**项目治理与知识**。职业事实不在这里，程序代码也不在这里。

| 目录 | 看什么 |
|---|---|
| `00-公共上下文/` | **当前做到哪。** 新 Chat / Agent 的第一入口、长期规则、当前接力、历史记录。 |
| `产品/` | **这个系统要做什么。** Product、阶段 Plan、项目原始目标。 |
| `系统规范/` | **系统怎么设计。** 冻结的产品/领域/数据/架构合同。 |
| `测试计划/` | **怎么证明实现没漂。** SDD 对应测试计划。 |
| `学习/` | **为了目标 JD 还要补什么。** JD 驱动学习与面试课程。 |
| `面试/` | **如何准备并训练面试。** 面试系统总纲、场景逻辑、材料体系、复盘与语音训练协议。 |
| `调研/` | **为什么做过这些技术判断。** 仍有价值的专项调研与故障复盘。 |

最常用入口：`00-公共上下文/说明.md`。

稳定真源不要复制到 docs：Career Facts 在 `../career-assets/职业事实.md`，运行时岗位真值在 `../app/db/runtime/`。
