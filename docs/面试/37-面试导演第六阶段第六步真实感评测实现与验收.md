# Interview Director P6-6｜真实感评测实现与验收

> 日期：2026-09-09
> 状态：**PASS / REALISM_FIXTURE_12_OF_12 / RUNTIME_STAGE_GATE_58_OF_58 / FULL_TEST_282_OF_282**

## 1. 目标

P6-6 不用“听起来像面试官”验收 Director，而用固定 transcript / replay 验证 Director 的机械决策是否接近真实结构化面试：何时追问、何时核验、何时换题、何时换阶段、何时停止，以及候选人实际能看到什么。

本阶段只评价 Director / Runtime 的 phase、probe、stop、risk、handoff 与 replay 行为。Candidate 模型回答质量不计入 Director 分数，`Perceived Realism` 继续留给 P6-7 真实用户 Voice Pilot。

## 2. 冻结评测面

最终固定 12 个 fixture，覆盖：

- Stop Discipline：强证据后停止同义追问，并跳过已满足 Phase；
- Ownership：模糊“我们做了”进入可证伪 Hypothesis / Cross-check；
- Claim Verification：强指标/强 Claim 在普通覆盖前核验；
- Truth Risk：HIGH/FATAL truth risk 高于普通 P0 coverage；
- Explicit Unknown：明确不会后禁止同义深挖；
- Anti-script：背诵感只触发 constraint-change challenge，不直接扣分；
- Time / Phase：hard budget 不再开启新深挖链；
- Route / Role：AI Tech1、HM、FDE 的 mission 与 phase target 可区分；
- Natural Transition：OPENING 与 CANDIDATE_QUESTIONS 不从技术题库随机抽题；
- No Coaching Leak：候选人可见 prompt 不泄露 reasonCode / score / hypothesis / claim debt；
- Replay Explainability：相同 transcript + plan 的语义 Decision 稳定；
- No Persona Bias：风格 override 不改变 Focus Signal 与评分 Authority。

## 3. RED 实际发现

P6-6 不是“给已有实现盖章”，固定 replay 真实发现并修复了以下 policy/runtime 缺口：

1. HIGH/FATAL `truth.*` Risk 会被普通 P0 coverage 抢先，无法优先回查自相矛盾事实；
2. `SCRIPTED_PATTERN` 只有文档语义，没有结构化 Runtime cue，会退化为普通 `PROBE_DEPTH`；
3. `ADVANCE_PHASE` 没携带下一 Phase target，AI Tech1 会错误回退到 Scene 默认 `signal.baseline`；
4. 下一 Phase 的 Focus 已经在前面拿够证据时，Director 仍会进入该 Phase 再多问一题；
5. 进入 `CANDIDATE_QUESTIONS` 后 Runtime 仍会抽技术 Corpus question；
6. 默认 `OPENING` 是空 Focus，但首次 `next_turn` 仍直接抽技术题，Phase State Machine 没真正落到候选人可见行为。

最初固定 fixture 为 `10/12 PASS`，truth risk 与 scripted-pattern 两项按预期 RED；后续三路线多回合 replay 又把 phase handoff、phase skip、候选人反问和 OPENING 缺陷转成稳定 RED，再逐项修复。

## 4. 最小修复

生产代码只改现有 Director / Runtime 合同，没有新增第二套架构：

- `interview-director.ts`：HIGH/FATAL truth risk 优先；增加 `SCRIPTED_PATTERN_CONSTRAINT_CHANGE`；`ADVANCE_PHASE` 携带下一未完成 Signal，并跳过 Focus 已 sufficient 的中间 Phase；
- `interview-runtime-host.ts`：把 reasoning challenge 与 Candidate Questions phase transition 透传到既有链路；
- `interview-voice-runtime.ts`：在 Director plan 存在时识别 `OPENING / CANDIDATE_QUESTIONS`，返回无 Corpus 绑定的自然过渡 TurnPack；普通 Phase 仍走既有 Retrieval；
- `interview-director-realism-eval.ts`：只投影可重复比较的语义 Decision，并提供 fail-closed realism summary。

没有新增 migration，没有新增 Director Tool，没有修改 Question Corpus、Candidate Evidence、Career Facts 或 Resume Evidence。

## 5. 三路线自演练

使用 AI Agent Tech1、高级前端 Deep Dive、ToB FDE Case 做多回合 replay，按 Director 给出的 target 推进并逐步模拟 Signal 已取得证据。

修复后确认：

- AI Tech1：OPENING → Project Anchor → Agent Technical / Coding Debug → Candidate Questions；Phase target 不再错误回退；
- 高级前端：Ownership / Scope → Frontend Arch & Perf → Full-stack Boundary；已满足 Phase 会被跳过；
- FDE：Requirement Clarify → Solution Boundary → Delivery Risk → Acceptance Trade-off → Candidate Questions；route focus 保持独立；
- 三条路线进入 Candidate Questions 时均使用自然反问过渡，不继续抽技术题。
