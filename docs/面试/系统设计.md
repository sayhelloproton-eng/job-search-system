# Interview System｜面试系统设计

Interview 是 Job Search System 的正式产品模块：它不是一份题库，而是一套由题目、检索、状态、追问、反馈和成长记录组成的 bounded runtime。

目标是让 AI 或人工界面都通过同一套可验证状态执行训练，而不是把全部题目和个人材料一次性塞进模型上下文。

## 1. 模块组成

```text
Question Corpus
      ↓
Retrieval / Graph
      ↓
Session State
      ↓
Interview Runtime
      ↓
Director / Follow-up / Challenge
      ↓
Observation / Debrief
      ↓
Growth / Review Queue
      ↔
Learning Bridge
```

- **Question Corpus**：题目 Family、canonical question、变体、Signal 与评分锚点。
- **Retrieval**：根据 Route、Scene、Session State 和历史出题记录选择下一题。
- **Session State**：保存当前轮次、问题、证据需求和已使用题目。
- **Director**：根据回答观察决定追问、澄清、挑战、推进阶段或结束本轮。
- **Growth Layer**：保存复盘、答案版本、弱点、知识缺口、训练趋势与 Review Queue。
- **Learning Bridge**：把真实知识缺口送入 Learning System，并在学习后安排复练。

## 2. Runtime Contract

核心操作：

- `interview.start_session`
- `interview.next_turn`
- `interview.observe_answer`
- `interview.resolve_evidence`

成长与反馈操作：

- `interview.finish_session`
- `interview.record_human_feedback`
- `interview.record_round_debrief`
- `interview.append_answer_version`
- `interview.record_growth_observation`
- `interview.select_best_answer`
- `interview.enqueue_review`
- `interview.get_growth_profile`

自适应训练与 Director：

- `interview.plan_training`
- `interview.complete_review`
- `interview.director_prepare_session`
- `interview.director_decide`
- `interview.director_get_state`
- `interview.director_finalize`

## 3. 数据层

公开数据库结构通过 migrations 重建：

```text
003_interview_v1.sql
004_interview_growth_v1.sql
005_interview_knowledge_v1.sql
006_interview_director_v1.sql
```

公开代码包含正式题库与运行时逻辑。当前公开回归同时验证基础 Formal Corpus 与扩展活动 Corpus，并验证 fresh clone 可以直接启动 Interview Runtime。

真实 Session、真实回答、评分、个人 Weakness、Review Queue 和面试历史只保存在本机 runtime DB。

## 4. Evidence Boundary

Interview Runtime 可以消费 Candidate Evidence，但不能创造 Candidate Evidence。

固定优先级：

```text
User-approved Facts / Evidence
> deterministic runtime state
> external observed data
> model inference
```

模型可以判断“回答证据不足”，但不能把推断升级为职业事实；学习完成也不能自动变成项目经验。

公开 clone 默认使用 synthetic candidate evidence。真实候选人 Evidence 通过本机文件注入，不进入 Git。

## 5. Voice / Text

文字与语音只是输入输出方式，不改变系统架构：

```text
Text or Voice UI
→ AI Session
→ Interview Skill
→ Interview Runtime
→ deterministic state
```

因此系统不依赖某一种语音产品，也不要求把 Runtime 状态交给模型自行维护。

## 6. Growth Loop

```text
Question
→ Answer
→ Observation
→ Debrief
→ Answer Version
→ Weakness / Knowledge Gap
→ Training Action / Review
→ Next Session
```

历史答案采用版本链而不是覆盖更新，才能判断“第一次怎么答、后来怎么改、是否真正改善”。

## 7. Public / Private Boundary

公开：

- Interview Runtime / Retrieval / Director / Growth 源码；
- Interview migrations；
- 公开题库与 synthetic candidate evidence；
- `interview-training` Skill；
- 本文件这份模块级设计。

私有：

- 真实面试记录与回答原文；
- 个人 Story Bank 与岗位专项材料；
- 候选人专属 Evidence；
- 个人 Weakness / Growth / Review 数据；
- 内部调研、实施过程、真实语音试点和验收记录。

这样公开仓提供可运行的 Interview System，而不是公开作者本人的面试档案。
