## 2. 新增长期资产

Migration `004_interview_growth_v1.sql` 新增：

- `interview_round_debriefs`：完整轮次复盘；
- `interview_answer_versions`：答案版本链，UPDATE 被数据库 Trigger 禁止；
- `interview_growth_items`：Weakness / Knowledge Gap / Expression Gap 当前档案；
- `interview_growth_observations`：每次出现、训练、改善、回退、解决的历史证据；
- `interview_best_answer_candidates`：当前最佳答案候选，不覆盖历史；
- `interview_review_queue`：后续复习/训练队列。
## 3. AI Growth API

Runtime 新增 6 个 Growth 操作：

- `interview.record_round_debrief`
- `interview.append_answer_version`
- `interview.record_growth_observation`
- `interview.select_best_answer`
- `interview.enqueue_review`
- `interview.get_growth_profile`

所有操作 `careerFactsMutable=false`；写操作继续使用 request-id 幂等账本。

Round Debrief 强制要求 strengths / weaknesses / interviewer intents / sentence critiques / replacement examples / knowledge gaps / expression gaps / next training plan 全部显式提供；缺项会失败，禁止“一句总结”冒充成长闭环。
