## 3. Schema 覆盖

DB-1 已建立五个逻辑域：

1. Source / Provenance：`interview_sources / source_documents / source_units`；
2. Compiled Knowledge：Signal、Route、Scene、Question Family、Question、Variant、Edge、Scoring Anchor；
3. Candidate Projection：Evidence Ref、Claim Boundary、Question↔Evidence Link、Answer Blueprint、Job Focus；
4. Session Working Memory：Session、Turn、Signal State、Hypothesis、Residual Risk、Claim Debt；
5. Feedback / Runtime Safety：Feedback、Training Event、Idempotency Request、FTS5 Search。

关键约束已经在数据库层表达：

- static semantic key 由主键保持唯一；
- `source_unit.provenance_key` 唯一，支持重复导入幂等；
-动态 Session / Feedback Event 使用独立事件 ID，不按正文去重；
- Enum / lifecycle / FK fail closed；
- Question Family ↔ Evidence Link 必须指向该 Evidence 自己的 Claim Boundary，不能借用别的 Evidence Boundary；
- `interview_sessions.job_id` 可为空，但非空时必须引用真实 `jobs.id`；
- `request_id` 为写操作幂等身份；
- FTS5 baseline 使用 `trigram`；
- 当前 Schema 不包含 Vector / Embedding / Vec1 表。
