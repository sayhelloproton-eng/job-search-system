## 1. 实现边界

只实现 P6-1 已冻结的最小 Director：

```text
Session Plan Snapshot
+ Existing Session Signal/Hypothesis/Risk/Claim Debt
+ Append-only Director Decision
+ Round Scorecard Snapshot
```

## 2. 最小 Schema

Migration 006 只允许：
- `interview_director_session_plans`
- `interview_director_decisions`
- `interview_round_scorecards`

Decision 必须满足 `UNIQUE(session_id, source_turn_id)`；Decision/Scorecard 采用 append/final snapshot 语义。## 3. RED 用例

1. fresh DB 有且只有三类 Director persistence；
2. prepare plan：Route/Scene/Signal/Phase 校验 fail-closed，exact retry 幂等；
3. 同一 `session + sourceTurn` 只能产生一个 Decision；
4. strong Claim debt 优先 `CROSS_CHECK_CLAIM`；
5. P0 UNTESTED 优先 `PIVOT_TOPIC`；
6. PROBING Signal 才允许 `PROBE_DEPTH`，且受连续深挖上限；
7. Focus Signal 足够后 `PIVOT_TOPIC / ADVANCE_PHASE`，禁止重复拷打；
8. phase/round hard budget 自动 `ADVANCE_PHASE / CLOSE_ROUND`；
9. explicit unknown 不继续同义追问；
10. finalize 只从现有 Signal/Turn/Risk 生成 evidence summary，不虚构 Anchor；
11. Hypothesis create / confirm / reject / supersede 与 Decision 原子提交；
12. Plan / Decision / Scorecard 快照不可被后续 UPDATE/DELETE 改写；
13. 所有工具 `careerFactsMutable=false`；
14. Director 不改变 82 题 Corpus、Candidate Evidence 或 Career Fact。
