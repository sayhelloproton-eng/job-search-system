# Job Search System — Product Overview

规范真源：`docs/系统规范/`，当前总版本 **FROZEN_V0.12**。

Phase 1：本地 JD 管理/筛选、招聘真实性、确定性匹配、简历版本与个人信息。当前 live Provider 只接 BOSS，并固定 `boss-agent-cli` CLI-first。

顶层视图：JD List / Resumes / Personal Info；JD Detail 在列表内展开。Phase 1 不打招呼、不投递、不发送简历、不执行浏览器写操作。

候选人唯一事实：`career-assets/职业事实.md`；证据：`career-assets/证据/索引.md`；当前画像：`career-assets/定位/候选人画像.md`。

`career-assets/` 同时承载当前职业资产与项目级核验材料；项目源码、绩效、Git、ONES 都跟随项目。完整求职执行流程由 `skills/job-search/` 承载。

`app/` 统一承载求职应用后端、Web、SQLite 与测试；根级不再平铺这些技术层。
