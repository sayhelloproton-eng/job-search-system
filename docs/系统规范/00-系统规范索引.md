## Current decisions that matter

- Phase 1 是 JD 管理与求职决策系统，不是自动投递 Agent。
- BOSS discovery/detail 只走已安装 `boss-agent-cli` 公共 CLI；其自带 `BOSS Agent Bridge` 属 CLI transport，不在本仓库 vendoring 第二份。
- Phase 1 不创建 application/browser-write 表，不提供 greet/apply/send-resume API，也不以自建 Chrome Extension 作为搜索/详情依赖。
- Provider 缺失字段保持缺失，不穿透私有结构或猜测补齐；`BLOCKED != CLOSED`。
- production/local bootstrap 不自动注入 demo jobs。
- `career-assets/职业事实.md` 是唯一活动候选人事实源；JD 只能选择事实，不能创造事实。
