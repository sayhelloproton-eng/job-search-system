# 运行与数据边界

## 1. 两种运行模式

### Demo

```bash
npm run demo
```

使用仓库内 `examples/` synthetic fixtures，适合第一次 clone、CI 和公开演示。

### Local private

```bash
CAREER_FACTS_PATH=/absolute/path/to/private/career-facts.md npm start
```

真实数据仍在本机，Git 不跟踪。

## 2. 数据 ownership

```text
Code / SQLite
= deterministic state / validation / side-effect truth

Career Facts / Evidence
= candidate truth

JD / Provider
= external observation

Model
= semantic judgment, never source of truth
```

## 3. 默认忽略

`career-assets/`、`.private/`、内部 handoff、runtime DB、候选人专属测试与材料不进入公开 Git。

## 4. Fresh clone contract

公开 clone 不依赖作者机器路径、作者账号或真实 Career Facts。只需要 Node.js 24+。

发布前：

```bash
npm run verify:public
```
